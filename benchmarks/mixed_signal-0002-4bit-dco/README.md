# GF180MCU 4-bit DCO benchmark

A compact analog circuit-to-layout benchmark. The candidate supplies a
16-code ring oscillator, real GDS, LVS, PEX, and characterization. A verified
GF180 standard-cell solution and an intentionally incomplete control are
included for benchmark calibration.

`solution/evidence` records the checked schematic and extracted-layout results
for the working solution.
