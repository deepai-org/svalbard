# Experimental GF180 CML transmitter

This directory contains a real transistor-level differential transmitter cell, not a behavioral placeholder. Mirrored unsalicided p-poly load banks feed a matched 10-finger NMOS differential pair and a 10-finger NMOS tail-current device. Each side has one always-on resistor and four identical active-low, PMOS-switched trim branches. The common thermometer code changes load resistance while `VBIAS` changes tail current; the nominal four-branch, 1.20 V point is selected from extracted simulation rather than assumed from schematic-only current.

![Generated GF180 CML transmitter layout](layout.png)

`layout.png` is a directly usable raster rendering of the generated GDS: the mirrored PMOS trim banks and five compact unsalicided p-poly resistor branches per side are above the adjacent differential pair, with the centered tail device and contacted substrate guard ring below.

`layout.tcl` generates and routes GF180 parameterized devices, places the pair banks adjacently with distributed gate contacts, puts the tail directly beneath the shared-source rail, keeps the matched output trunks on metal3 at the outer drain edges, adds redundant via transitions, explicit PMOS well taps, and a continuously contacted substrate guard ring, labels the eleven interface pins, and emits MAG/GDS into disposable scratch. The bounded flow runs bias characterization, pre-layout ngspice, Magic DRC, Netgen LVS, full coupled-RC extraction down to 1 mOhm, extracted ngspice at 1.25 and 2.5 GT/s, and an actual GDS render.

Run it with:

```sh
make serdes-tx-smoke
```

Passing nominal evidence is written to `scratch/serdes-tx-last.json`; the inspected layout image is `scratch/serdes-tx-layout-last.png`. `run_programmable_pvt.py` separately searches load code and bias over MOS, resistor, voltage, and temperature corners using either schematic or full-RC extracted netlists. `run_extracted_robustness.py`, `run_extracted_mc.py`, `run_extracted_mc_recovery.py`, `run_extracted_ac_noise.py`, and `run_extracted_prbs.py` add adversarial transient, seeded statistical, transient-aware calibration, AC/noise/supply, and PRBS-7 characterization against the same extracted cell.

The current full-RC matrix passes all 135 core combinations (five MOS corners, three resistor corners, three temperatures, and three supplies). Across those calibrated 2.5 GT/s cases, sampled differential magnitude is 0.522--0.621 V, threshold crossing is 17.0--26.8 ps, average supply current is 5.34--7.43 mA, and the minimum output floor is 2.045 V. The separate pad-boundary ceiling check fails all 135 cases because the standalone ideal-edge/50 fF environment has no selected pad, ESD clamp, or package model; its worst overshoot is 4.23 V. This failure is retained rather than treated as core qualification.

The nominal full-RC adversarial sweep passes 37 of 47 deliberately independent and combined cases. Every 25--200 fF symmetric load, tested 25/75 through 150/50 fF load imbalance, 5--80 ps edge, 25--150 mV supply-ripple case at 100 MHz--1 GHz, 2.97--3.63 V supply, and 1.25--3.125 GT/s rate passes. A 120 ps input edge loses center-sample swing. Nonzero input-skew and the three combined cases violate the deliberately strict 25 mV positive/negative sampled-swing balance; they retain adequate crossing time, and are recorded as interface-envelope failures rather than relabeled as layout passes.

At nominal voltage and temperature, 50 reproducibly seeded samples are run independently for public-model global variation, MOS mismatch, and their combination. Applying the same 0.40--0.65 V sampled-magnitude, 25 mV symmetry, 80 ps crossing, 1--8 mA current, output-floor, and common-mode checks gives 128/150 on the first DC-selected transient. Transient-aware `VBIAS` adjustment recovers all 22 outliers in at most three attempts, producing 150/150 for this bounded sample set; all recovered cases keep four trim branches enabled and select 1.14--1.23 V bias. This is calibration-coverage evidence, not a production-yield estimate. The public p-poly model exposes global statistical resistance but requires an externally supplied `mis_r` value and provides no resistor-mismatch distribution, so local resistor mismatch is explicitly not sampled or invented.

Nominal extracted small-signal analysis reports 1.85 V/V differential gain, 6.03 GHz -3 dB bandwidth, 1.70 V/V gain at 2.5 GHz, 233 uV RMS integrated differential output noise from 1 MHz to 20 GHz, and a worst differential supply coupling of 0.00121 V/V over that band. The common-mode output follows the supply at up to 1.003 V/V, as expected for resistive loads. A two-period PRBS-7 run analyzes the final 127 bits and all 64 transitions with no missing crossing, 0.635 V minimum center-sample differential margin, 37.0 ps mean core delay, and 0.011 ps peak-to-peak deterministic jitter. These PRBS numbers use ideal complementary input drivers and a 50 fF core load, so they do not include pad, package, channel, or source jitter.

All results are experimental pre-silicon public-model evidence. They are not PCIe compliance, package/channel, reliability, model-validity, EM/IR, ESD, or foundry qualification evidence. A qualified pad/ESD cell, bond/package model, board/channel envelope, local resistor-mismatch bound, post-fill extraction, and provider-accepted high-frequency/reliability limits remain required before analog-top freeze; running more core SPICE cannot supply those missing facts.
