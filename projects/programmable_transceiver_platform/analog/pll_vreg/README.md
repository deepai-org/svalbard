# `pt_pll_vreg`: ring-PLL supply regulator (PDN-04 / RA-17)

Owner: pads (2026-11-10). Consumer: wired RX (`pll_ring`): **two instances, pll_tx and pll_cdr** (PD25/PD28; pll_host
runs on the raw pll island rail). **PD28 (2026-11-11): the published cell is the packed variant, 0.241 mm² per instance**
(gate cap 15,000 µm², output cap 10,000 µm²); see "PD28" at the end. Sections below describe the PD20 cell (0.285 mm²).
Status: **laid out** (`pll_vreg_layout.py` → `generated/pt_pll_vreg.gds`, Magic DRC 0, LVS unique, KLayout precheck clean);
extracted reruns in `evidence/pll_vreg-ext*.json` (see "Layout" below).

## Why

A3 measured an extracted `pt_pll_ring` supply pushing of 150 MHz/V static and 158 MHz/V at 78 MHz. With the A2
macro ripple (40–90 mV at 78 MHz) this gives ≈ 29 ps peak DJ and a −25 dBc spur. The demand is PSRR ≥ 20 dB over
10–160 MHz and a ring DJ from the supply below 5 ps peak. (risk: PDN-04)

## Circuit (`pt_pll_vreg.spice`, generated by `pll_vreg.py:netlist()`)

Ports `VIN VOUT VSS BYP ATB_OUT ATB_G`.

- Pass device: native `nfet_06v0_nvt` source follower, W 300 × 20 µm, L 2.7 µm, D = VIN (the pll island rail), S = VOUT.
  The output impedance is 1/gm, so the ring's current changes do not move VOUT and the PLL sees no extra pole.
- Gate VG: a slow OTA (NMOS pair, PMOS mirror on VIN, ~4 µA self-biased tail) regulates VOUT to
  0.9 × VIN (300 k / 2.7 M divider). That holds a 0.31–0.50 V dropout at every corner, so the pass device stays
  saturated. Gate capacitor: 30,000 µm² thin-oxide MOS cap to VSS. It sets the dominant pole and, together with
  L = 2.7 µm, the HF PSRR floor (the Cgd and DIBL paths).
- Start-up PMOS VIN→VG, gate = VOUT: it pulls VG up only while VOUT < VIN − |Vtp|. In regulation it is off
  (Vsg = dropout).
- Output capacitor: 20,000 µm² thin-oxide MOS cap for the ring's GHz current pulses.
- `BYP` (core register, active high): a W 1000 µm PMOS shorts VIN→VOUT (38 mV drop at 8 mA). This is the
  fallback and the 810 MHz mode (see the limit below).
- ATB: VOUT and VG through 20 kΩ to ATB leaves. Observe both. Forcing ATB_G overrides the OTA (MΩ output),
  so VOUT can be set externally: this gives a silicon Kvdd/jitter-vs-supply sweep.

Area estimate: ≈ 0.08 mm² per instance (pass 16k µm² of gate, caps 50k µm², R/OTA/bypass ~5k µm²).

## Limits and hand-off (wired RX)

- **810 MHz at ss needs the ring supply ≥ 3.02 V** (open-loop extracted ring, VCTRL = VDD: ss 2.75 V → 733 MHz,
  2.9 V → 778 MHz, 3.3 V → 887 MHz; tt 2.75 → 923, 2.9 → 973, 3.3 → 1091 MHz; `ring/ring.json`). No series
  regulator from a 3.05–3.35 V die rail can deliver that with a saturated pass device. This is a headroom limit,
  not a regulator choice: an NMOS needs Vgs above VOUT, and a PMOS loses its PSRR in triode. So the 810 MHz mode
  runs in `BYP` (unregulated, A3 jitter), unless the ring is resized for ≥ 900 MHz at 2.6 V ss (wider header/tail).
  480/625 MHz modes run regulated with margin. (risk: PLV-01)
- VOUT tracks 0.9 × VIN below ~100 kHz. That is inside the PLL bandwidth (2.6 MHz) and corrected by VCTRL.
- Layout: see the "Layout" section.
- Needed bits: one `BYP` register bit per instance, **reset 1** (bypassed, i.e. the v3 behaviour; firmware clears it
  for the 480/625 MHz modes after the island is up), and two ATB leaves per instance (ATB_OUT, ATB_G). (risk: PLV-01)

## Layout (2026-11-10, pads)

`pll_vreg_layout.py layout` builds the cell with the converter netlist-to-layout kit (`analog/converters/lib/convkit.py`:
PCell rows, private Metal2 risers, Metal3 channel tracks, Metal4 trunks; VIN/VOUT/VSS trunks 4 µm, VG 1 µm) and
publishes `generated/pt_pll_vreg.gds` (top `pt_pll_vreg`), `pt_pll_vreg.ext.spice` (Magic, C threshold 0), the LVS
report and `pt_pll_vreg-layout.json` / `-kldrc.json`. Layout netlist: `pt_pll_vreg_layout.spice`.

Implementation mappings versus `pt_pll_vreg.spice` (the extracted reruns use the drawn cell, not these mappings):
pass device 60 × W 100 µm units (same W 6000 µm, L 2.7 µm; 100 µm is the native model's W bin limit); bypass PMOS 20 × W 50 µm; MOS caps unchanged
(20 × 38.73², 40 × 22.36²); resistors as 50 µm series units of `ppolyf_u_1k` (3.3 V high-R poly; every resistor
sees ≤ VIN) instead of `ppolyf_u_1k_6p0`.

Native device (NAT rules): Magic's GF180 tech grows NAT only 0.26 µm over the native COMP, which fails NAT.1
(2 µm). The generator draws the native units with the guard ring 2.4 µm from the channel COMP (NAT.2) and all gate
poly inside NAT (NAT.9), then `nat_fix()` regrows NAT to 2 µm and extends DUALGATE over it (NAT.8, DV.2) in the
exported GDS. That GDS is re-extracted by Magic and LVS-compared again (unique match).

Checks: Magic DRC 0; netgen LVS unique (layout and NAT-fixed GDS round trip); KLayout tapeout precheck main 0 /
antenna 0. Size **452 × 632 µm = 0.285 mm²** per instance (the 0.08 mm² estimate counted gate area only; guard
rings, the 2 µm NAT surround and the routing channels triple it).

  (≈ 29–33 ps pk at 40–90 mV, 78 MHz ≈ 0.9 % UI); its `BYP` bit and ATB leaves are not needed (`pllvreg.config` already

### PD33 (2026-11-11): area is still too large for v5, so a dual-output cell is proposed (schematic only) (risk: INT-24)

The coordinator needs ≤ 0.06 mm² per ring. The area is set by guard-ring overhead. The 60 single-finger native PCells
take 0.058 mm²; one nf = 60 PCell measures 0.021 mm². The pass device itself cannot shrink: L 1.8 costs
2.5–3.6 dB of PSRR, and a smaller W runs out of ss dropout.

Proposal `pt_pll_vreg2` (one cell for pll_tx and pll_cdr, about 0.12 mm²):
- a shared divider (30k/270k), OTA and gate cap (30,000 µm²);
- two native followers, each with its own 3,000 µm² Cout and BYP.

Schematic results for the open-loop output, with the extracted r9 ring:
- PSRR −23.3 / −24.4 / −24.3 dB (tt/ss/ff);
- DJ 2.54 / 1.93 / 2.71 ps at 60 mV.

These match the published packed cell. Evidence: `evidence/pd28-vreg-area-options.json`; interface-changes PD33.
Not laid out yet. It needs a strapped nf = 60 native sub-macro, because the PCell does not strap its fingers.

### PD36 (2026-11-11): `pt_pll_vreg2` built and published (the coordinator approved PD33)

This is the cell to instantiate: **one cell for pll_tx and pll_cdr** (pll_host is deleted, X1). The PD28 single
`pt_pll_vreg` stays in `generated/` only as the fallback.

**Files**
- Generators: `pll_vreg2_pass.py` (pass macro) and `pll_vreg2_layout.py` (top cell).
- Outputs: `generated/pt_pll_vreg2.{gds,ext.spice}`, `-lvs.txt`, `-layout.json`, `-kldrc.json`, `pt_pll_vreg2_layout.spice`, `generated/pt_vreg_pass/`.

**Ports** `VIN VOUT_TX VOUT_CDR VSS BYP_TX BYP_CDR ATB_OUT ATB_G`
- VOUT_TX is the output inside the OTA loop; VOUT_CDR follows the same gate.
- ATB_OUT observes VOUT_TX.
- BYP = 1 shorts that output to VIN.

**Circuit**
- Shared: divider 30k/270k, OTA, gate cap 30,000 µm² (20 × 38.73² MOS units).
- Per output: one `pt_vreg_pass`, a 3,000 µm² output cap and a W 1000 µm BYP PMOS with its own inverter.
- OTA bias resistor: 17 × 30 µm units (510 kΩ, was 500 kΩ).

**Pass macro `pt_vreg_pass`**
- One nfet_06v0_nvt PCell, W 100 / L 2.7, nf = 60, strapped by hand:
  - a Metal1 gate bar on the polycontact row;
  - 2 + 2 Via1/Metal2 bars on the source and drain columns;
  - Metal2 edge pins.
- 199.1 × 102.9 µm. Magic DRC 0, LVS unique against 60 parallel devices.

**Cell checks**
- Size: 447.9 × 390.5 µm (bbox −29…418.9 × 0…390.5) = **0.175 mm² for both rings**. That replaces 2 × 0.241 = 0.482 mm² (−0.307 mm²).
- Magic DRC 0; netgen LVS unique, including the NAT-fixed GDS round trip.
- KLayout precheck: main 0 / antenna 0.
- The PD33 estimate was 0.12 mm²; the convkit routing channels (about 19 µm × 4) cost the difference.

**Extracted reruns**
- Same benches as `pll_vreg.py`, via `pll_vreg2_ext.py`. The output under test is the open-loop VOUT_CDR (worst case); the other output carries 7 mA.
- Ring load: the extracted r9 ring.
- Evidence: `evidence/pll_vreg2-ext-*.json`.
