# ctl_ports.txt: every control port pt_digital_macro must present to the analog top (coordinator decision:
# decode glue lives in the digital macro; the register map follows the cells).
# port | width | reset | encoding | register field(s) today ("-" = none exists) | note (consumer pins are in pt_chip.conn)
# encoding "direct" = the port is the field's bus bits unchanged (width and reset must match the field);
# anything else is a decode the macro must implement. reset = value after reset = the cell's safe state.
# Ports of a switched island read 0 while that island is off (regfile gating rule, checked in sim/tb_top_boundary.sv);
# "reset" is the value with the island on.
# All ports are static (change only while the consumer is stopped) unless the note says "dynamic".
# "en" encoding everywhere below: (state == active) & island_on[k] of the consumer's island (D-EN: READMEs say state != off).
