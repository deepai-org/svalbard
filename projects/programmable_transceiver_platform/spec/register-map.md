# Control register map

Generated by `rtl/gen/gen_regfile.py` from `analog-architecture.json:control_fields` and
`debug-controls.json`. Do not edit; regenerate. The machine-readable map is
`register-map.json`; bench headers are `rtl/gen/pt_regmap.h` and `rtl/gen/pt_regmap.py`.

Map hash `0x3CAC` (read at 0x09), ABI version `0x0003` (0x08), ID `0x5356` (0x00).
171 generated registers (36 debug/fallback at 0x40-0x5D, 135 analog at 0x60-0xE4) carrying 322 fields (1273 bits); 38 commit rules.

## SPI ABI

Unchanged: SPI mode 0, MSB first, one 32-clock transaction per CS_N low period: command8 /
address8 / data16. Command 0x80 writes, 0x00 reads (read data is shifted out during the last
16 clocks). The flat 8-bit address space holds every register, so no page register is used.
The register file is clocked only by `HOST_SCLK` and works with every PLL and oscillator stopped.
A write (and a COMMIT) takes effect on the SCLK falling edge that follows the 32nd rising edge;
in mode 0 SCLK returns low before CS_N rises, so that edge is always present. Clocks beyond the
32nd never repeat a write.

Encoded wide fields (`decode: mant_exp`): the register holds a code e:m (mantissa width per
field); the analog_cfg bus carries the decoded value m (e = 0), (2^mb + m) << (e - 1), saturating
at the decoded width. `rtl/gen/pt_regmap.py` provides `mant_exp_code(value, mb, db)` and
`mant_exp_value(code, mb, db)`. Fields marked direct (no shadow) take effect on the write itself;
COMMIT/REVERT do not touch them.

## Per-board calibration sequence

Host-run (FPGA over SPI) using on-chip measurements; every result is written into its trim field,
then `debug.calibration.tag`/`valid` record the run (D-CAL-1, package placement tolerance):

1. Power: core, then islands (`debug.island_power`), check `ISLAND_STATUS`; regulated ring PLLs
   (`pllvreg.config.*_bypass` = 0) are held off for >= 50 us by the macro.
2. LO termination and level: step the LO termination code, read the LO amplitude detector on ATB
   (ADC or ATB pad); keep the code with the on-level inside the B3 window.
3. I/Q phase and amplitude: TX->RX loopback tone, measure the image with the RX ADC capture
   (`MEM_CAPTURE`), minimise with the quadrature phase/amplitude trims.
4. RX match: sweep `lna.match.ctrim` (direct trim) for the best loopback or detector level;
   `lna.match.rterm`/`se` only for the documented fallback boards.
5. TX back-off: `rfdriver.gain.code` for the board loss (P1..P4 placement), checked on the
   detector/ATB.
6. Wired: termination trim, CTLE code and de-emphasis from PRBS loopback error counts
   (`debug.pattern`, `status.pattern`), CDR phase trims `cdr.phase_trim.p0..p7` (direct) and
   `cdr.config.cap_rcsel` from raw-word PRBS/comma errors.
7. Bandpass ripple: `consolidation.bbfilter.qtrim` (direct) from the BB_I/Q tap response.
8. Write `debug.calibration.tag` (board id or epoch) and `valid` = 1.

## Macro clock plan (SP-01)

Macro clock harmonics within +/-1 MHz of the RF channel are avoided by the host word rate
(FPGA) and `debug.host_link.rate`: 312.5 Mword/s full rate (core 78.125 MHz; harmonics
2343.75/2421.875/2500 MHz) for every 2.4 GHz channel except channel 3 (2422 MHz, 0.125 MHz from
the 31st harmonic), which uses 250 Mword/s full rate (core 62.5 MHz; 15.5 MHz clear). The
reduced-rate fallbacks are clear by > 1 MHz except: half rate ch 3 (0.12) and ch 11 (1.06);
quarter rate ch 3, 7 (0.59), 11 (1.06) at 312.5 Mword/s and ch 3, 6, 9, 14 at 250 Mword/s. The
RF sample clock (40/80 MHz) has harmonics at 2400/2440/2480 MHz (>= 2 MHz from every channel).

## Commit, reset and CDC

SPI writes go to shadow registers (write-time range/encoding check per register; fields wider than 16 bits are range-checked at commit). Writing COMMIT (0x06 bit 0) validates the complete shadow (split-field ranges, every rule above, break-before-make against the active set, and - while the legacy payload ENABLE is 1 - that only live fields differ) and copies shadow to active in one SCLK edge, or rejects the commit, keeps the prior active configuration and latches CONFIG_ERROR (control_semantics.illegal). Bit 1 reverts shadow to active.

The register file is clocked only by SPI SCLK and asynchronously reset by RESET_N AND POR. Active fields are quasi-static: they change only on a successful commit, which also toggles commit_toggle. A consuming clock domain that must see a coherent multi-bit value synchronizes commit_toggle through two flops and reloads its local copy on a toggle edge; the next commit cannot occur for at least one more 32-clock SPI transaction. Purely analog consumers see each field change once per commit; stopped-only fields are changed only while their outputs are isolated.

Reset: `rst_n` = RESET_N AND POR. It asynchronously returns every shadow and active register to
its declared default (the safe state): every island off, every driver tristated, every
termination and pull released, every ATB switch open, every clock select stopped. Release
reset with CS_N high and SCLK idle low; the first SCLK edge must follow reset release by the
cell recovery time.

## Safety enforcement

A control output whose island list is non-empty is driven to all-zero (isolation value) unless every listed island has its switch enabled and reports power-good (or has pgood_override set). Zero is the off/disconnected/disabled encoding of every state, enable, branch and select field. Register contents keep their programmed values; only the outputs are clamped, so re-enabling an island restores the committed configuration. Island status (0x0A): power-good is a ratiometric rail-up flag, so power-good = 1 with debug.island_power = 0 is the back-drive signature (the island rail is being powered through a control, pad or bias path; analog/island_support README I4).

ATB0 is the force bus and ATB1 the sense bus. Each bus closes at most one switch (code 0 = all open). ATB1 may select any node. ATB0 may select only device replicas, matching structures and the six overridable bias/reference nodes; selecting an overridable node on ATB0 requires its bias_override bit, and setting a bias_override bit requires ATB0 to select that node, so the internal source and the bench never drive one node together and an overridden mirror is never left floating. Island nodes are disconnected while their island is off; supply monitor taps are not gated so a switched-off island can be confirmed dead. Nodes marked hardware=false have no tap: their codes are rejected on both buses. Core reference-chain nodes (VBG, ROOT_REF, TRK_<island>) carry the force preconditions of analog/core_support/README.md as commit rules instead of override bits. ATB all-off gap: >= 20 ns from deselect to the next select on one bus (atb_switch_dead_time_s; group/pad non-overlap up to 5.7 ns). The break-before-make rule puts a zero commit between two non-zero codes, i.e. at least one 32-clock SPI transaction, which exceeds 20 ns for any SCLK below 1.6 GHz. control_semantics.switch_dead_time_s (4 ns) remains the analog-switch figure for other selects.

A commit may not change one of these fields directly from one non-zero code to a different non-zero code; it must commit the zero (stopped/off/open) code first. Two SPI transactions separate the commits, far exceeding the 4 ns switch dead time in control_semantics.switch_dead_time_s.

## Debug, consolidation and core group notes

- **`debug.island_power`** (0x40): Local island power-switch enables. Core and host are never switchable and have no bit.
- **`debug.pgood_override`** (0x41): Fallback for a failed island power-good detector: treat the island as powered when its switch is enabled.
- **`debug.clk_select`** (0x42): Source of each clock domain. internal_pll selects the functional path (clockmux/pll/clocktree as configured); the others connect the named input receiver directly. Changing between two running sources is rejected: go through stopped (break-before-make). host_follow (P3-3) is the pll_ring locked to the FPGA-forwarded H2D_CLK followed by the prescaler; it is the converter/sample and host clock source in passive-LO mode, where REF_IN and AUX_CLK carry the LO. Allowed for conv_sample and host_clk only.
- **`debug.bb_tap`** (0x43): BB_I/BB_Q pad mode. observe_* drives the pads from the tristate observation buffer; inject_* connects the pads (externally driven) to the named internal node. One mode at a time by encoding.
- **`debug.rf_rx_bypass`** (0x44): LNA bypass switch from RF_RX into the mixers (external board LNA).
- **`debug.rf_tx_bypass`** (0x45): Low-power mixer/txsum output to RF_TX with rfdriver off (external board PA).
- **`debug.rf_bb_bypass`** (0x46): Per-stage RX baseband bypass (I and Q together).
- **`debug.wire_bypass`** (0x47): CTLE bypass (terminated input straight to the slicer path).
- **`debug.wtx_ext`** (0x48): External serial data on WTX_EXT_P/N drives the wired TX output stage input in place of the serializer.
- **`debug.wmon_select`** (0x49): WMON buffered wired monitor (analog/wired_rx/README.md wmon_sel): off = buffer disabled and output tristated.
- **`debug.atb`** (0x4A): Analog test bus switch selects; code = atb_nodes[].code, 0 = all switches open.
- **`debug.bias_override`** (0x4B): Disconnect the internal source of an overridable bias/reference node so ATB0 can force it (see atb_policy).
- **`debug.clk_obs`** (0x4C): CLK_OBS source and power-of-two divider (analog-side prescaler). off = pad tristated. pt_clk_obs has 8 inputs and N<=7: sources without a cell input are rejected (analog/timing/README.md register-map gap).
- **`debug.wclk_obs`** (0x4D): WCLK_OBS recovered/divided wired clock source and divider. off = pad tristated.
- **`debug.dbg_obs`** (0x4E): DBG_OBS0/1 digital status mux: 0 = tristate, 1 = constant 0, 2 = constant 1, 3 = commit toggle, 4+n = obs_status[n], 36 = live combined reset level rst_n (RESET_N AND POR; 1 = released). Any reset also returns the select to 0, so during reset the pad is tristated and reads the board level.
- **`debug.wdbg_obs`** (0x4F): WDBG_OBS wired status mux: 0 = tristate, 1 = constant 0, 2 = constant 1, 3+n = wire_status[n].
- **`debug.replica`** (0x50): Characterization oscillators routed to CLK_OBS: ring-oscillator speed monitor and standalone VCO replica with its own divider.
- **`debug.host_link`** (0x51): Host GPIO link mode fallback (consumed by pt_host_physical). D2H drive itself is hostio.controls.d2h_enable. rate is the reduced-rate transport fallback: the host link word side and the whole transport core run at host word clock /1, /2 or /4 (pt_host_rate_clock); change only while ENABLE=0, then lower the wired/RF line rates to match. Reset is full rate.
- **`consolidation.bbfilter`** (0x52): Shared I/Q baseband filter bank (consolidation items 1-2, pass-2 P2-2): replaces the rxfilter_*, txfilter_* and pga_* field sets, which now read zero. direction drives bbfilter en/dir_tx; bw, gain and finite_zeros are the block's only programmable settings (analog/rf_rx/README.md section 4); rx_direct is filter-less RX for TX-through-filter loopback; tx_dac_direct drives txmix sel_dac (analog/rf_tx/README.md).
- **`consolidation.pll`** (0x53): Shared PLL/VCO bank (consolidation item 3, P2-2): replaces rfpll.config and wirepll.config (read zero). owner drives pll EN (off = 0); output_divider drives W1..W10; feedback_n drives the one-hot NS16..NS128 (integer-N, power of two, no fractional accumulator, no reference divider, fixed charge pump: analog/timing/README.md); phase_tap drives PH1..PH8. rfpll.state is the state of the shared PLL; wirepll.state reads zero. lock_window/lock_tolerance/lock_count configure the standard-cell counter lock check rtl/pt_pll_lock.sv (FBCK = VCO/16 counted against REF over the window; expected FBCK/REF = N/16 from feedback_n); it runs while owner != off and its result is status.pll_lock.
- **`consolidation.wiredtx_stage`** (0x54): consolidation-pass.md item 4: TMDS is a configuration of the wired TX output stage. stage selects serial (CML with source termination) or tmds (current sink, termination off). tmds.* fields remain the TMDS-configuration controls. bits_per_cycle selects 1, 2 or 4 bits per ring cycle for both the serializer and the deserializer. rate_mode (shared by serializer and deserializer) selects 4/half/full bits per ring cycle.
- **`consolidation.txmix`** (0x55): Saturated (constant-envelope) mixer mode from the RF TX power-recovery pass: shorts mixer degeneration for BLE/802.15.4/GFSK/LoRa. 0 = linear (OFDM).
- **`consolidation.quadrature`** (0x56): Retired in pass 3 (P3-1): mode is reserved and reads 0; the group keeps its address 0x56.
- **`consolidation.detect`** (0x57): detect det_src_tx: sense the WIRE_TX pad instead of WIRE_RX (analog/wired_rx/README.md: no field existed).
- **`debug.pattern`** (0x58): PRBS/pattern generator and RX checker in pt_digital (pass-2 P2-6). tx_mode payload (0) keeps the legacy behaviour (wire_trim[15] selects PRBS31). inject and check_clear are live levels: one error is injected / the checker is cleared on each 0->1 transition, synchronized into the word-clock domain. Status is read-only at status.pattern.
- **`rxmix.offset`** (0x5A): Mixer TIA offset-correction DAC pt_rxmix_ofsdac (analog/rf_rx/README.md): 6-bit sign-magnitude, bit 5 = sign (1 = negative), bits 4:0 = magnitude (ofs[4:0], about 8 mV per LSB); 0 and 32 are both zero offset. Fields correspond to the requested rxmix_i.offset / rxmix_q.offset.
- **`core.biasgen`** (0x5B): Master bias generator gf180mcu_ocd_ip__biasgen (README field names bias.*). All resets are the safe state. ref_sel_fine is gated in hardware (fine_eff = ref_sel_fine & ref_sel_coarse) and also rejected at commit. Bring-up order (analog/core_support/README.md 'Register requirements'): (1) islands off, all fields at reset; (2) ena=1 and core.refchain.bgap_ena=1 (sinks 7/3, trim 8), wait >= 100 us; (3) ref_sel_vbg=1, ref_sel_coarse=1; (4) power an island, set core.refchain.dist_en_<island>=1, then the block enables. Per-die trims (bandgap trim, idac2_source) are applied by host software after every reset.
- **`core.refchain`** (0x5D): Bandgap (README bgap.*) and bias-distribution root trunk-leg enables (README dist.en_<island> = EN_<ISLAND>). Trunk enables are not island-gated: the documented idac2 trim runs dist_en_debug=1 with the debug island unpowered.
- **`debug.freq_count_a`** (0xE8): Generalized frequency counter instance a (PLL/TX ring; spec/consolidation-pass.md P3-7, rtl owned by the digital hardening agent): counts the selected source against the reference over a window; enable = source != off. Placed at 0xE8 (free tail of the 0x60-0xEF block) because the 0x40-0x5F debug block is full.
- **`debug.freq_count_b`** (0xEA): Generalized frequency counter instance b (CDR ring; spec/consolidation-pass.md P3-7, rtl owned by the digital hardening agent): counts the selected source against the reference over a window; enable = source != off. Placed at 0xEA (free tail of the 0x60-0xEF block) because the 0x40-0x5F debug block is full.
- **`core.aosc`** (0x5E): SUB-04/RA-1: always-on oscillator pt_aosc EN (consumers: fc_src[4] and debug observation). Live; reset on. While an RF payload runs (ENABLE=1 with digital.transport_config.payload_iq = 1 (I/Q owner)) the register file forces the output to 0 regardless of this field, so the aosc cannot spur the RF receive chain.
- **`debug.calibration`** (0x5F): D-CAL-1 per-board calibration record. The calibration sequence (spec/register-map.md "Per-board calibration sequence") runs from the host over SPI using the on-chip measurements (loopback, detectors, ATB, ADC); it writes its results into the trim fields themselves and then stamps this record. Direct live fields (no commit needed).
